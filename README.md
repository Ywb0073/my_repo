# git-practice

Git 协作流程演练仓库 · 模拟「管理员 + 开发人员」双角色

</div>

## 这是什么

用两个 GitHub 账号模拟公司里的代码协作：
一个账号当**管理员**（建仓库、保护 main、审查合并），
另一个当**开发人员**（开分支、提交、发起 PR）。

## 团队成员

| 角色 | GitHub 账号 | 职责 |
| --- | --- | --- |
| 管理员 | _(待填)_ | 建仓库、设置分支保护、审查并合并 PR |
| 开发人员 | _(待填)_ | 在 feature 分支上开发，发起合并请求 |

## 当前功能

- `add(a, b)` — 加法
- `subtract(a, b)` — 减法
